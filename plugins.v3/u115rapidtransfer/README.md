# 115只秒传重试（U115RapidTransfer）

适用于 MoviePilot V3 的文件整理插件：当整理目标存储为 **115 网盘（`u115`）** 时，强制**只允许秒传**，禁止回退到慢速的 OSS 分片普通上传；若秒传未命中，则按用户设定的等待时间自动重试整理。

## 核心功能

1. **只秒传拦截（零普通上传）**
   - 通过 `ChainEventType.StorageOperSelection` 代理 `u115` 存储操作，在 `upload()` 阶段仅执行 115 开放接口 `/open/upload/init`（含必要时的 `sign_check` 二次校验）。
   - 仅当 115 返回 `status == 2`（秒传命中）时才视为上传成功；否则立即返回失败，不会请求 OSS 上传凭证或发起分片上传。
2. **秒传失败延迟重试**
   - 监听 `EventType.TransferFailed`，精准识别因本插件拦截导致的 115 秒传失败。
   - 按配置的等待时间（秒）通过宿主 `add_plugin_once_job` 注册延迟重试，并持久化待重试队列（重启不丢失）。
   - 到期后调用 `TransferChain().redo_transfer_history(history_id)` 重新触发整理。
3. **灵活过滤与手动干预**
   - **仅对媒体文件限制只秒传**：默认开启，仅对音视频文件强制只秒传，字幕/NFO/海报等小附件仍可正常上传。
   - **最小限制文件大小（MB）**：可按文件体积阈值放行小文件。
   - **远程命令与接口**：支持远程命令 `/u115_rapid_retry` 以及 `/status`、`/retry`、`/clear` API 查询和管理待重试队列。

## 配置说明

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 启用插件 | 启用或停用 115 只秒传拦截与重试 | 关闭 |
| 发送通知 | 秒传拦截、重试成功或达到上限时发送通知 | 开启 |
| 仅对媒体文件限制只秒传 | 仅对音视频媒体文件强制只秒传，附属文件正常上传 | 开启 |
| 最小限制文件大小（MB） | 小于该大小的文件允许普通上传，0 表示不限制 | `0` |
| 失败重试等待时间（秒） | 秒传失败后等待多少秒再发起下一次重试（最小 10 秒） | `600` |
| 最大自动重试次数 | 单个文件最多自动重试次数；0 表示仅阻止普通上传 | `5` |
| 兜底巡检周期 | 定期巡检到期的待重试任务（兼容重启恢复） | `*/5 * * * *` |
